## Ambiguities and Notes
1. **Package Version Matching**: Vulnerability version matching is approximate based on CVE publication year. Conservative estimates used for `affects_pinned_version`.

2. **Legacy vs Patched**: Two webserver configurations exist:
   - Legacy (nginx 1.20.0) on web-old01
   - Patched (nginx 1.24.0) on web-new01
   Both have identical firewall rules allowing 0.0.0.0/0 access to HTTPS.

3. **SSH Access**: Only users in the `sudo` group can SSH into web servers. The `admin` user (secret clearance) has access; `appuser` (developers group) does not.

4. **Database Access**: PostgreSQL only accepts connections from the web subnet (10.0.1.0/24), implementing network segmentation.

5. **Default Deny**: Implicit default-deny rule applies to all unlisted access patterns.

## Recommendations
1. **Immediate**: Address KEV vulnerabilities (CVE-2023-38408, CVE-2024-6387 for OpenSSH)
2. **Short-term**: Upgrade legacy nginx (1.20.0) to patched version (1.24.0)
3. **Medium-term**: Review firewall rules allowing 0.0.0.0/0 to HTTPS
4. **Long-term**: Implement network segmentation for database access beyond subnet-level
